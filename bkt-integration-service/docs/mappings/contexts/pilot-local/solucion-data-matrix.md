# Matriz de mappings - Solucion

Esta matriz separa los campos que podrian venir de Jira de los campos que se generan despues por procesamiento interno.

## Resumen

- Nuevos mappings confirmados en este batch: 0.
- Pendientes: campos que pueden rellenarse en Jira, pero no tienen `sourceField` confirmado.
- Excluidos: campos generados por procesamiento interno o adjuntos tratados por flujo especializado.
- Bloqueados por motor: arrays de objetos que requieren fan-out o colecciones hijas.
